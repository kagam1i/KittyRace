# Kitty Race

**Kitty Race** — это cozy **pixel-art runner** в духе Subway Surfers, но с другим настроением и камерой.

- **Камера:** top-down / 3⁄4  
- **Полосы движения:** 5  
- **Стиль:** pixel-art  
- **Тема:** лесная тропа  
- **Вайб:** спокойный, уютный, не аркадный  
  (ближе к *Stardew Valley*, чем к *Temple Run*)

Игрок управляет котиком, который бежит по дороге **вниз экрана**.  
Мир движется **сверху вниз**, при этом кот остаётся примерно на одном месте по оси **Y**.

---

## Геймплей

### Основные механики
- **Препятствия**, требующие реакции игрока:
  - `jump` — перепрыгнуть препятствие
  - `slide` — проскользить под препятствием
  - `sidestep` — уйти в соседнюю полосу
- **Сбор рыбы** — основной коллектабл на трассе

### Управление
- **ПК:**
  - `W / ↑` — прыжок  
  - `S / ↓` — слайд  
  - `A / ←`, `D / →` — смена полосы
- **Телефон / планшет (тач):**
  - свайп влево / вправо — смена полосы
  - свайп вверх — прыжок
  - свайп вниз — слайд

## Визуальный стиль и атмосфера

- пиксельная графика с чёткими спрайтами
- лесная палитра и декоративные элементы по краям дороги
- отсутствие резких эффектов и агрессивного темпа
- акцент на **cozy-ощущениях** и плавном игровом процессе

## Техническая информация

### Технологии
- **React**
- **Redux Toolkit**
- **Vite**
- **CSS / Tailwind**
- управление через **keyboard + touch gestures**
- адаптив под **десктоп / планшет / телефон**

### Адаптив
- десктоп — оригинальный масштаб и визуал
- планшет и телефон — уменьшение элементов **1:1**, без изменения логики и коллизий
- управление пальцем для мобильных устройств
