# Kitty Race — карта файлов (FILES_MAP)

Таблица ниже показывает, какой файл за что отвечает и что в нём можно / нельзя менять,
чтобы не сломать геймплей и архитектуру.

## Основные файлы и директории

| Путь | Ответственность | Что МОЖНО менять | Что НЕЛЬЗЯ менять |
|-----|-----------------|------------------|-------------------|
| src/main.jsx | Точка входа React | Провайдеры | Игровую логику |
| src/App.jsx | Корневой компонент | UI-обёртки | Game state |
| src/app/store.js | Redux store | Новые slice | Существующие reducers |
| src/index.css | Глобальные стили | Адаптив, CSS-переменные | Геймплей |
| src/audio/audioManager.js | Звук | Громкость, SFX | Логику игры |
